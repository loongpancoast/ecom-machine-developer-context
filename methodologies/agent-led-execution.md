# Agents and reliable tools

Agents should be able to choose tools, inspect results and change their approach when evidence or outputs are poor. A fixed sequence of prompts will not fit every product or creative task.

Use ordinary tested software for transactions, permissions, budgets, retries, job tracking and rendering. An agent should not guess whether a campaign was created or submit the same paid job again because a request timed out.

Keep sources, prompts, generated work, edits and results available when an agent or model changes. Test a replacement before using it for live work. This is how the system stays useful as agentic AI improves.

A node view may help explain video dependencies and selected takes, but no particular editor or orchestration platform is required. Historical diagrams and examples are methodology reference, not supplied working software.

Use Codex and Claude subscriptions through supported access; paid APIs are limited to video generation. Verify limits before committing. The current [requirements](../REQUIREMENTS.md) define scope, negotiable pricing and acceptance. Supplier and 3PL work is secondary.
