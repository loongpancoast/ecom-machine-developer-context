# Ad-to-page continuity — original excerpts

> Historical creative method, not measured conversion evidence. No source-course examples, actual products or media included. Framework rights/attribution need review. Angle/image/hook taxonomies are optional source conventions; references are not included.

## The Core Principle

**The image's job is not to sell. Its job is to stop the scroll and open a conversation.** The ad copy continues that conversation. The advertorial does the heavy lifting of belief and education. The PDP closes. Break congruency at any step and the funnel leaks.

If anyone asks you to "just spam some ugly images" or "use a winning ad copy on a different image" — that's the failure mode the entire system exists to prevent. Politely refuse to do it that way and explain why before producing the work.

A good angle has:
- One emotional tension or belief shift it owns
- One avatar segment it's clearly for
- One awareness level it's pitched at (Unaware / Problem-Aware / Solution-Aware / Product-Aware / Most Aware)
- A native visual that can carry it (one of the 8 archetypes — see `references/image-archetypes.md`)

For each angle, declare:
```
ANGLE NAME: [short tag]
DESIRE / TENSION: [the emotional spike]
AVATAR SEGMENT: [who specifically]
AWARENESS LEVEL: [exactly one — never mix]
IMAGE ARCHETYPE: [from the 8]
HOOK FAMILY: [primary + backup from the 8 hook types]
```

## Phase 4 — Build the Four-Asset Set

For each chosen angle, produce four assets that lock together. They must read as one continuous conversation.

### 4a. Image Ad Brief

Use `prompts/image-ad-brief.md`. Output is a designer-handoff brief, not a finished image. Every brief contains: concept summary, headline options, visual composition (with layout details), typography direction, color palette, CTA-on-image (often "none"), branding elements (often "minimal" — ugly ads break when packaging dominates), and optional enhancements.

### 4d. PDP / Landing Page Handoff

Note for the dev team: which advertorial leads here, what the user's last belief state is when they land, what the offer must reinforce, where the social proof hits. One paragraph per asset, not a redesign brief.
