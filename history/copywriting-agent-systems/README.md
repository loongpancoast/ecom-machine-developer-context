## What is not included

- Course transcripts and proprietary prompt bodies; Evolve/GTE/EAM learning is summarized with attribution.
- The claude-ads copywriter/strategist bodies; historical installation/migration variants are described, not republished without license review.
- Raw owner interviews, private identities, actual tested products, customer/supplier records, credentials or original local source paths.
- Unreviewed historical branches/stashes, all other agent families, broader vault contents or all local skills.
- See the separate [media history](../media/DEVELOPER-INDEX.md) for included video and image references.
- A working scraper, scheduler, dashboard, platform integration, deployment or proof of commercial outcomes.

These are sanitized originals or clearly labeled excerpts, not verbatim unchanged sources. Generic runtime paths in prompts are illustrative application-relative destinations, not links to hidden original files. Required application guardrails, schema adapters and platform integrations are not bundled. The private provenance manifest remains outside this public repository.
