## Failed attempts and corrections to preserve

1. **A source-looking language bank can still lack source provenance.** A private agent memory explicitly corrects an earlier claim that an asset represented a captured-post archive; the underlying item was a synthesized research report instead (HCS18). Preserve source IDs, raw capture references and independent-source groups. Do not infer original quotes or corpus size from a polished report. Private subject, pricing and counts are intentionally omitted.
2. **Dashboard writes were mistaken for agent execution.** HCS17 distinguishes local keyword/template artifact generation from invoking a role's actual prompt. Later sections add harness-run evidence, making the registry internally historical and time-dependent. Record separate states for `spec exists`, `route matches`, `template generated`, `agent invoked`, `external read`, `external write readback` and `business result`. None of the historical run counts is exported as current proof.
3. **Substring routing stole unrelated requests.** HCS17 records a keyword token matching inside another word and a vendor-sourcing intent routing to recruiting. The recorded correction used word-boundary scoring and narrower intent vocabulary. Test positive cases and neighboring negative cases; do not only check that a new route can fire.
4. **Template-only copy review missed customer-facing text.** HCA04–HCA05 preserve the lesson that section schemas and preset defaults, accessibility text, empty states and administrative metadata surfaces differ. Read complete scoped files; edit customer-facing values while preserving admin labels, IDs, keys, URLs and HTML shape. Reparse after unique-match replacements and rescan.
5. **Ad longevity was treated as profit.** HCS02–HCS03 equate sufficiently old active ads with winners. That inference is not supported by ad-library observation alone. Retain dates as a persistence signal, then corroborate economics separately. Concurrently observed advertisers did not necessarily start at the same time; the owned July procedure records that correction (HCA06's source).
6. **Traffic estimates became revenue-looking numbers.** HCS02 uses website visitors × assumed conversion × assumed order value. Keep all assumptions and period alignment explicit; do not promote the result to measured revenue or apply whole-store traffic to one SKU.
7. **Heuristic gates were over-generalized.** Older documents prescribe fixed research counts, margin multiples and spend cutoffs; the March score description is also ambiguous about fractional weights versus a 100-point total (HCS01–HCS05). A real implementation needs tested arithmetic, confidence/coverage treatment and business-specific economics. Do not silently inherit historical constants.
8. **Funnel symptoms were treated as causes.** HCS08 treats no spend as a failed angle and other metrics as single-cause copy diagnoses. Auction/approval/tracking/offer/stock problems can produce the same symptom. Test alternative explanations before rewriting or killing a product.
9. **Wrapper success concealed missing evidence.** HCA10 names all-null transcripts, null profiles, field-name mismatch and same-name entity confusion. Keep access state distinct from content quality and entity relevance; preserve raw responses so a downstream model can inspect the actual evidence.
10. **A prompt's self-verification is not an independent result.** HCA06 separates writer and checker; its own instruction to count distinct endpoints cannot establish actual request count when an endpoint repeats. Implement both counters. Old model labels, reported tests and historical registry status are not freshly verified runtime capability.

## Rights and review boundary

The new analytical summaries are not replacements for source licenses. Evolve, GTE and EAM methods are acknowledged; no wholesale prompt/transcript is included. The local materials disagree about some framework attribution and expand “RMBC” inconsistently. Do not treat those expansions as authoritative definitions or silently standardize them. No actual customer/owner interview, tested-product record, supplier identity, account credential or local original path belongs in this public candidate.
