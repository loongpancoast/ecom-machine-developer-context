# C15 — Test actual output before expanding architecture

**Historical lesson — assistant-written summary, not an owner quotation.**

Older packages are starting points, not trusted dependencies or mandatory requirements. Evaluate existing approaches against a real reference and inspect their finished output before adding contracts, abstractions or integrations.

A discontinued experiment is not an adopted implementation. Preserve useful work, but choose subsequent changes based on demonstrated gaps rather than the presence of earlier plans.
