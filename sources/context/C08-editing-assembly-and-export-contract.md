Assemble final video: `ffmpeg-python` (10,999★) for concat/caption/format; `pyCapCut` / `pyJianYingDraft`
for CapCut drafts; `video_concat` / Composer semantics for overlays + dynamic text; platform exports
(9:16 Reels/TikTok, 1:1 Feed, 16:9 YouTube); captions (watch-time lift) + music. This is the
editing layer the single-asset router lacks.

If a step needs paid generation, hand it back to the owning paid specialist (it STOPs at the gate) —
never run a paid tool yourself (CapCut cloud render, if ever invoked, is paid → STOP, not local). (Cap full text: `AGENT-MESH-SPEC.md` §2.)
